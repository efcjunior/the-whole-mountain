# The Whole Mountain

**The Whole Mountain** is a discipleship multiplication app by Jesus Said Go.

This app is part of Everson's volunteer development workspace for the Jesus Said Go mission.

## Purpose

The app is intended to support Christian discipleship group multiplication. A leader forms a group, walks disciples through a structured study, and the platform tracks multiplication across generations.

## Current Phase

Documentation analysis and validation planning.

Before production development starts, requirements will be consolidated and validated through a dedicated prototype repository: `the-whole-mountain-prototype`.

## Workspace Rule

This directory is for app-level context, traceability, and planning. It should not become the main source repository unless that decision is made explicitly.

Implementation repositories should live under `repos/` and be versioned in their own Git repositories.

## Documents

`docs/incoming/` contains documents and artifacts received from outside sources, preserved as they arrived.

Examples include specifications, brand direction, mockups, prompts, handoff notes, and reference code.
